# Format guidelines

Under development

## Frontmatter

Each blog post needs clearley defined frontmatter with the following keys:

- title: 'string'
- description: 'string'
- pubDate: 'YYYY-mm-dd'
- heroImage: 'string'
- thumbnail: 'string'
- tags: ['string']
- draft: true || false

## Thumbnails and hero images

- Thumbnails and hero images are located inside `/src/assets` directory.
- Should follow 16:9 ratio.
- heroImage: 1200px x 630px
- thumbnail: 400px x 225px
