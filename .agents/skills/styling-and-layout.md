# Styling and layout

Use this when adjusting visual design, layout structure, or page composition.

## Where to work

- Shared layout elements: [src/components](../../src/components)
- Page wrappers: [src/layouts](../../src/layouts)
- Styles: [src/styles](../../src/styles)

## Rules

- Prefer the existing visual patterns already in the project.
- Keep layout changes minimal and consistent with the blog design.
- Avoid introducing broad design resets or framework-heavy styling unless explicitly required.
- Preserve accessibility and responsive behavior when changing spacing, typography, or layout.

## Validation

- Check that the change does not break page structure or readability.
- Run the build or local preview after significant styling updates.
